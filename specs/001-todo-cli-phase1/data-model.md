# Data Model: In-Memory Python Console Todo App (Phase I)

## Entities

### Task
Represents a single todo item in the system.

| Field | Type | Description | Validation |
|-------|------|-------------|------------|
| `id` | `int` | Unique identifier for the task | Must be positive, generated by System |
| `title` | `str` | Short description of the task | Non-empty, max 100 chars |
| `is_completed` | `bool` | Current status of the task | Default: `False` |

## State Transitions
- **Add**: Creates a new `Task` with `is_completed=False`.
- **Toggle**: Flips `is_completed` status.
- **Update**: Modifies the `title` of an existing `Task`.
- **Delete**: Removes the `Task` entity from the memory store.
